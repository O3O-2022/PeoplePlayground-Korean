People Playground 한국어 패치 (비공식) {version}
게임 버전 1.27.18 기준 / Windows 전용
https://github.com/O3O-2022/PeoplePlayground-Korean

[설치]
1. Steam 라이브러리 → People Playground 우클릭 → 관리 → 로컬 파일 보기
2. 이 zip 안의 내용물 전체를 그 게임 폴더에 넣습니다.
   People Playground.exe 옆에 winhttp.dll, doorstop_config.ini, BepInEx 폴더가 있으면 성공입니다.
3. 게임을 실행합니다. 첫 실행은 조금 오래 걸립니다.

※ 게임 폴더에 이미 winhttp.dll이 있다면 다른 모드 로더가 설치된 상태입니다.
   덮어쓰기 전에 무엇인지 확인하세요.

※ Steam으로 켜는 게임 폴더에 넣어야 합니다. 게임을 다른 드라이브로 옮긴 적이 있으면
   예전 폴더가 남아 있을 수 있으니 위 1번(로컬 파일 보기)으로 연 폴더에 넣으세요.

[그림 속 글자]
제목 로고, 표지판, 아이콘 속 글자도 한글로 바뀝니다.
그림은 원본 그대로 두고 글자만 번역하려면 BepInEx\Translation\ko\Image 폴더를 지우세요.

[단축키]
ALT + T : 한국어 ↔ 영어 원문 전환 (그림 속 글자도 같이)
ALT + R : 번역 파일 다시 불러오기

[제거]
게임 폴더에서 winhttp.dll, doorstop_config.ini, .doorstop_version, BepInEx 폴더를 지우면 됩니다.

[번역 오류 제보]
위 GitHub 주소의 Issues에 남겨 주세요.
BepInEx\PPGKorean_untranslated.txt (번역 안 된 채 화면에 나온 문장 목록)를 첨부해 주시면 큰 도움이 됩니다.
